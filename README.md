## Scoring Rules

Final objective score consist of:
- **Scoring program score**
- **Manual-reviewed process score**

The process score is adjusted according to the following rules:
- **Object-object collision** or **object-scene collision**: deduct 5 points
- **Teleportation** or **passing through walls**: deduct the **full score of the current level**
- **Picking up objects without proper contact**: deduct the **pickup portion of the current level score** (half of that level’s score)

## Ranking Policy

Ranking is determined as follows:
1. Teams are ranked first by **scoring program score**
2. If scoring program scores are tied, ranking is determined by **reviewed process score**
